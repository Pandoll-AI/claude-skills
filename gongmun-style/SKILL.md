# 공문서 문체 스타일 (Gongmun Style)

한국 공공기관에서 통용되는 **개조식(箇條式) 공문서·약식보고서 문체**로 텍스트를 변환하거나 새로 작성하는 스킬이다. 핵심은 두 가지다. 첫째, 만연체 서술을 **명사형 종결의 개조식**으로 압축한다. 둘째, **원문의 정보는 하나도 잃지 않는다**. 문체와 형식만 바꾸고 내용·수치·사례·근거는 전량 보존한다.

## 언제 쓰나

- 일반 산문/초안을 한국 기관 내부 보고용 문체로 다듬을 때
- 계획서·검토서·품의서·현황보고·결과보고 등 내부 문서를 작성할 때
- "공문체/개조식/보고서체로 바꿔줘", "공공기관 형식으로 정리해줘" 류의 요청

## 출력 형식 선택

요청 맥락에 따라 세 가지 렌더링 중 선택한다. 사용자가 명시하지 않으면 **(B) 마크다운형**을 기본으로 하되, "한글(HWP)에 붙여넣을 것"·"관공서 제출용"이면 **(A) 개조식 마커형**을 쓴다.

- **(A) 개조식 마커형** — `□ ○ - * **` 리터럴 마커 + 들여쓰기. HWP·아래아한글·관공서 양식에 그대로 붙여넣기 좋다.
- **(B) 마크다운형** — 마크다운 헤딩(`##`), 굵은 두괄 표제(`**표제** — 내용`), 중첩 리스트, 표준 마크다운 표. 화면·노션·깃 등에서 잘 렌더된다.
- **(C) JSON 브리프** — 다운스트림 자동 렌더링용 구조화 출력. 스키마는 `references/style-rules.md` 참고.

### HWPX 파일로 실제 출력할 때 (서식 층)

이 스킬은 **문체 층**만 담당한다. `.hwpx` 파일을 직접 생성·편집해야 하면 조판은 별개 문제다.

기관마다 용지·여백, charPr 정의, 폰트 매핑(본문 휴먼명조 등), 항목 간 스페이서 규격이 정해져 있다.
소속 기관의 서식 규칙 문서가 있으면 **그것을 진실원본으로 삼고 이 스킬은 문체에만 적용한다.**

특히 **항목 사이 간격은 문체 규칙만으로 재현되지 않는다.** 한글 문서에서 `□`·`○`·`-` 각 항목 뒤에 지정 크기(흔히 6pt)의 빈 문단을 스페이서로 삽입하는 관행이 있는데, 이는 마크다운에 표현할 수 없는 조판 정보다.

문체와 서식을 섞지 말 것. 마크다운 산출물에 pt 단위를 적으면 안 되고, 반대로 HWPX 생성 시 개조식 종결을 빠뜨리면 안 된다.

세부 규칙·마커 위계·표 스타일·JSON 스키마는 **반드시 `references/style-rules.md`를 읽고** 적용한다. 변환 전후 비교 예시는 `references/example.md`에 있다.

## 핵심 문체 규칙 (요약)

1. **명사형 종결 + 불필요한 "함" 제거** — 평서형(~한다/~된다/~이다)을 명사형으로 끝낸다. 단, 한자어 동작명사는 "함"을 붙이지 말고 **명사로 끝낸다**: "검토함→검토", "활용함→활용", "마련함→마련", "예방함→예방", "확인함→확인". "함"은 이미 명사가 끝맺는 자리에 붙는 군더더기다. 명사로 환원되지 않는 "~하고자 함 / ~되도록 함 / ~수 있음 / ~필요 / ~있음 / ~임"은 그대로 둔다.
2. **두괄식 + 괄호 표제(모든 모드 공통)** — 중주제는 반드시 주제어를 **괄호**로 먼저 제시하고 내용을 잇는다. 마크다운형에서도 괄호를 유지한다. 예: 개조식 `○ (추진배경) …` / 마크다운 `- **(추진배경)** …`.
3. **객관적 관찰자 시점** — 감정적 형용사·수사·과장("혁신적", "획기적", "매우 중요한")을 배제하고 사실·관찰·판단만 적는다.
4. **불릿 위계** — `□(대주제) > ○(중주제) > -(소주제) > *(세부) > **(최세부)`. 마크다운형에서는 헤딩+중첩 리스트로 대응시킨다(대응표는 레퍼런스 참고).
5. **표 우선** — 항목·대상·기준처럼 정형화되는 내용은 산문 대신 표로 정리한다.
6. **내용 보존 (최우선)** — 원문의 모든 내용·수치·사례·근거를 빠짐없이 포함한다. 요약·축소·생략 금지. 문체와 형식만 변환한다.

## 작업 절차

1. 원문을 읽고 논리 단위(대주제)를 식별한다.
2. 각 단위를 두괄식으로 재배열한다 — 결론/주제를 앞에, 근거/세부를 뒤에.
3. 만연체 문장을 명사형 개조식으로 압축한다(정보 손실 없이).
4. 정형 항목은 표로 옮긴다.
5. 선택한 렌더링(A/B/C)으로 출력한다.
6. **검증** — 원문 대비 누락된 수치·항목·표가 없는지, 모든 종결이 명사형인지, 모든 중주제가 두괄식 표제로 시작하는지 확인한다.

## 주의

- 정보를 지어내지 않는다. 원문에 없는 수치·기관명·일자는 추정 시 "추정" 표기를 남긴다.
- 마커(□○-*)나 표제어 괄호는 텍스트 내용에 중복으로 넣지 않는다(렌더러가 마커를 붙이는 (C) 모드에서는 특히 주의).
- 표 셀의 숫자도 (C) JSON 모드에서는 문자열로 출력한다.
